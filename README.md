# AI Study Buddy

A smart learning assistant built for the IT23304 Object Oriented Programming record (Team 17), Madras Institute of Technology, Anna University.

**Team:** Sriram R (2025506050), Pooja S (2025506066), Shrivathsan A (2025506074), Mohammad Athil B (2025506124)

## Live demo
Open the GitHub Pages link of this repository. Demo login: `student` / `study123`.

## Features
- Login with a 3-attempt limit
- Subject management (Core, Practical and Elective subjects)
- Subject quiz with level change and feedback
- Study session log and progress dashboard

## OOP concepts shown
Classes and objects, function overloading, operator overloading (`==` on IDs), friend functions and classes, inheritance, templates and inline functions, runtime polymorphism, exception handling, file handling, and STL (map, vector, list).
